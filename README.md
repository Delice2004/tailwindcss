# TailwindCSS Startup Project

A responsive multi‑page website template built with **Tailwind CSS**.  
This project demonstrates modern front‑end practices with clean design, reusable components, and responsive layouts suitable for startups, agencies, businesses, and SaaS platforms.

---

## 🚀 Features
- Fully responsive design using Tailwind CSS
- Hero section with CSS‑only animated word cycle
- Portfolio grid with hover effects
- Client testimonials section
- Pricing plans with clear call‑to‑action
- Blog section for content publishing
- Support form with contact details
- Footer with company info, links, and newsletter subscription

---

 Project Structure
- `index.html` – Main landing page
- `src/input.css` – Tailwind source styles
- `src/output.css` – Compiled Tailwind CSS
- Additional HTML pages for Portfolio, Blog, Support, etc.
